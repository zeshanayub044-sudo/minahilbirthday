# Minahil — My Forever Love ❤️

A complete, static birthday gift from Muneeb to Minahil for 19 October 2026. The approved porcelain, baby pink, blush rose, champagne and cherry red palette is preserved.

## Open and publish
Open index.html directly, or serve this folder with any static web server. No installation, build, framework, backend or third-party assets are required. The files at the repository root are ready for GitHub Pages.

## Personalization
Edit birthdayConfig at the top of script.js. It contains names, date, time zone, theme values, all supplied long-form writing, chapter names and feature flags. The gift is available before, on and after the birthday.

Long passages use small reading pages. Read It All shows the complete original paragraphs. The letter has its own scroll area. All artwork is original inline SVG or CSS; hearts use a single bounded Canvas animation engine.

## Audio and privacy
Sound starts off. The toggle enables quiet synthesized chimes. To use a local instrumental, place a licensed file in assets/audio/ and set musicFile to its relative path. No broken remote audio or autoplay is used.

Progress is saved only in this browser under minahil-forever-love-v1. A return visit offers Continue or Start From the Beginning. The heart jar is a manual tap counter; it does not detect emotions. No interactions are sent anywhere. Relive Everything clears journey state and starts again.

## Accessibility and motion
Native dialog focus handling, inert inactive scenes, keyboard navigation, pointer and keyboard hold support, touch-friendly controls, safe-area spacing and reduced-motion fallbacks are included. Every celebration can be skipped or closed with Escape.

The standard storm uses 315 hearts on desktop and 150 on narrow screens, with distributed internal origins across a grid covering the entire viewport. Hearts gather into one large heart, reveal the message and rain away. Replaying leaves the current chapter intact.

## Files
- index.html — fifteen chapters and reusable SVG artwork.
- style.css — approved theme, responsive layouts and animation styles.
- script.js — personalization, reading system, navigation, interactions, progress and effect lifecycle.
- assets/decorative/ — optional future local illustrations.
- assets/audio/ — optional local instrumental file.

The previous approved eight-chapter version is backed up locally outside this deployable folder. Development verification is also kept outside this folder.

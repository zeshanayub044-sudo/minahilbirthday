# A Magical Birthday for Minahil

Open index.html in any modern browser. No installation, build, account, or server is needed. All artwork is original inline SVG and CSS, with no external fonts or media requests.

## Personalization
Edit birthdayConfig at the beginning of script.js for names, date, timezone, title, signature, and effect switches. The prominentGreeting and loveReply fields use {name}. Edit the other message paragraphs in index.html to change the letter and wishes. Names inside data-name, data-boyfriend, and data-father spans populate automatically.

## Optional music
Add an audio file you own or have permission to use under assets/, then set musicFile to 'assets/your-song.mp3'. The music button becomes available; music plays only when tapped. Without a file, the disabled music control makes no network request.

## GitHub Pages
1. Upload index.html, style.css, script.js, and assets/ to the root of a GitHub repository.
2. In Settings > Pages, choose Deploy from a branch, your branch, and / (root).
3. Open the URL GitHub provides when deployment completes.

Netlify and Cloudflare Pages can also host this folder directly, with no build command. No public deployment has been created for this personal gift.

## Controls
Use the scene buttons to advance, or the bottom left arrow to revisit a chapter. On phones the love cards support swiping, arrows, and keyboard left/right. Tap the gift to open the internally scrollable letter. Tap the candle button to make a wish. The little bottom right heart hides a note. Relive The Magic resets the gift, cards, candles, messages, and transient effects without reloading.

The countdown uses Asia/Karachi calendar days; it never restricts access. Reduced-motion preferences disable decorative animation. Inactive scenes are inert and hidden from assistive technology. On very short screens, only the current scene's content panel scrolls to preserve access to every control.
